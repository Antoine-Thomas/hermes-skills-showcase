# Example 03: WordPress Local Setup

## Command
```
hermes run local-flywheel-setup --site-name "demo-site" --php-version "8.2"
```

## Result
```
✓ Local by Flywheel environment detected
✓ WordPress 6.6 installed
✓ Admin user created (username: admin)
✓ Site accessible at http://localhost:8080
✓ Configuration saved to ./config/
```

## Notes
- Demonstrates the WordPress setup workflow
- Before/after: empty environment → fully configured WordPress site
- Time gained: automated setup vs manual Local by Flywheel configuration
