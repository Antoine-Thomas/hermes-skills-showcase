# Overview

This showcase presents a curated selection of Hermes Agent skills for video automation, system optimization, and WordPress management. Each skill is designed to be autonomous and ready-to-use within the Hermes Agent ecosystem.

# Use-cases

## Video Automation
- Generate talking head videos from photos and audio using LivePortrait or SadTalker
- Assemble final videos with background music, logos, and titles
- Optimize GPU usage and control rendering speed (11.1x realtime)

## System Optimization
- Auto-update OmniRoute with free AI model selection
- Clean Windows temp files and manage scheduled tasks
- Monitor system health and gateway status

## WordPress Automation
- Install and configure WordPress sites on Local by Flywheel
- Automate WP-CLI tasks (updates, plugins, themes, database)
- Backup and restore complete sites (files + database)
- Deploy sites to remote servers (FTP/SFTP, SSH/rsync)
