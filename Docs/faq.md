# FAQ

**Q: How do I install a skill?**
A: Clone the hermes-skills repository, then copy the skill directory to `~/AppData/Local/hermes/skills/`. Configure your API keys in the `.env` file.

**Q: Where can I buy the full version?**
A: Visit https://www.agensi.io/@thomas-leroyer to purchase the commercial license with full source code and all skills.

**Q: Are the scripts in this showcase functional?**
A: This repository is a showcase only. It contains examples, documentation, and summaries of capabilities. The full version with complete source code must be purchased.

**Q: What licenses apply?**

**Q: How do I get updates?**
A: Update notifications are handled via the OmniRoute auto-update skill. For the full version, updates are provided through your Agensi.io account.
